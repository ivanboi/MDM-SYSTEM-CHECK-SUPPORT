# MDM SystemCheck — Public Support

This repository is the **public issue tracker** for the MDM SystemCheck Android application. The application source code is maintained in a **separate private repository**.

- [Report a bug](https://github.com/ivanboi/MDM-SYSTEM-CHECK-SUPPORT/issues/new?template=bug_report.yml)
- [Request a feature](https://github.com/ivanboi/MDM-SYSTEM-CHECK-SUPPORT/issues/new?template=feature_request.yml)

**Privacy:** All issues are public. Do not publish passwords, access tokens, IMEI, serial numbers, personal data, confidential IP addresses or hostnames, or unredacted diagnostic CSV files.

**Security:** Do not disclose security vulnerabilities in public issues. Use a private contact channel with the maintainer.
